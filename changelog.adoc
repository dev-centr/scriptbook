= Changelog

== Unreleased — 2026-09-08

* All twelve PlayTime diagrams now ship editable Mermaid sources, explicit Themed SVG v1 manifests, preserved fixed originals, and generated standalone-adaptive and host SVGs.
* Antora and specification image paths remain stable; diagram image blocks are marked for progressive enhancement by the shared themed-SVG runtime.

== Unreleased — 2026-08-18

* Example playbooks for first-class coding monos (`examples/fonts/install-*.cmk`): Cascadia Mono, JetBrains Mono, Fira Code, Iosevka, Monaspace, JetBrains Mono Nerd Font. Intents (`cli.install`), not host shell translation. Catalog ids in `equivalence-rules-cli`.

== 0.2.0 — 2026-08-13

* Name the three layers: CentrMark (format), PlayTime (engine in `lib/`), Scriptbook (CLI app)
* Intent steps: `::: step [intent="cli.install" tool="gh"]` bound via libequivalence
* Host Awareness: baked probe cascade (`lib/embed/probes.generated.json`); no EE call to learn OS
* `::: choose` / `::: ask` / `when-answer` / `when-context`
* CLI: `--format`, `--catalog`, `--answers`, `--prefer-mutable`
* Sidecar records host snapshot, answers, and resolved command
* Example: `examples/install-gh.cmk` (same file on every OS)
* Specs: `spec/playtime.adoc`, `spec/host-awareness.adoc`, updated playbook profile + sidecar
* Illustrated Antora component (`docs/`) for the org hub; figures for layers, bind flow, facets, Host Awareness ratchet
